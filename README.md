# طَيّة | Tayya

مشروع متجر عربي لـ طيّة مبني من واجهة React/Vite وباك إند Node.js/Express.

## تشغيل المشروع محليًا

افتح نافذتي Terminal داخل مجلد المشروع.

الواجهة:
    cd client
    npm install
    npm run dev

الباك إند:
    cd server
    npm install
    npm run dev

افتح رابط Vite الذي يظهر في نافذة الواجهة. تمرر الواجهة طلبات /api إلى الخادم المحلي على المنفذ 5000.

## الموجود حاليًا

- صفحة رئيسية عربية باتجاه RTL وهوية فحمية/تركواز/نحاسية.
- أقسام مجسمات الديكور والأشكال والهدايا والمجسمات حسب الطلب.
- معاينة تفاعلية لملفات STL وOBJ و3MF، مع خيارات المادة واللون والحشو ودقة الطبقة.
- تقدير أولي بالجنيه المصري. معدلات الحاسبة الحالية قيم بداية قابلة للضبط في server/index.js.
- إرسال طلب التسعير ورفع الملف إلى مجلد server/uploads، مع تسجيل بيانات الطلب في server/data/quotes.jsonl.
- ملفات الطلبات والمجسمات المرفوعة مستثناة من Git عبر server/.gitignore.

## إضافة المنتجات

افتح صفحة الإدارة من `http://127.0.0.1:5173/admin` لإضافة المنتجات وتعديلها وحذفها مع الصور والأسعار والأوصاف. تحفظ بيانات المنتجات في `server/data/products.json`، وتحفظ الصور في `server/uploads/products`.

الأسعار الفعلية والكتالوج النهائي ما زالا بحاجة إلى بيانات المنتجات. تخزين بيانات العملاء والملفات مناسب للتطوير المحلي فقط، ويحتاج إعداد حماية وتخزين مناسب قبل النشر.
