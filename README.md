# طَيّة | Tayya

مشروع متجر عربي لـ طيّة مبني من واجهة React/Vite وباك إند Node.js/Express.

## تشغيل المشروع محليًا

افتح نافذتي Terminal داخل مجلد المشروع.

الواجهة:
    cd client
    npm install
    npm run dev

الباك إند:
    cd server
    npm install
    npm run dev

افتح رابط Vite الذي يظهر في نافذة الواجهة. تمرر الواجهة طلبات /api إلى الخادم المحلي على المنفذ 5000.

## الموجود حاليًا

- صفحة رئيسية عربية باتجاه RTL وهوية فحمية/تركواز/نحاسية.
- أقسام مجسمات الديكور والأشكال والهدايا والمجسمات حسب الطلب.
- معاينة تفاعلية لملفات STL وOBJ و3MF، مع خيارات المادة واللون والحشو ودقة الطبقة.
- تقدير أولي بالجنيه المصري. معدلات الحاسبة الحالية قيم بداية قابلة للضبط في server/index.js.
- قاعدة Postgres على Neon تحفظ المنتجات والأقسام والطلبات وإعدادات المتجر وطلبات الطباعة.
- دخول Google لحساب إدارة واحد، والتحقق من الصلاحية في الخادم قبل قراءة الطلبات أو تعديل بيانات المتجر.
- Vercel Blob خاص لحفظ صور المنتجات وملفات الطباعة بعد إضافة متغير التخزين إلى مشروع server.

## إضافة المنتجات

افتح صفحة الإدارة من `http://127.0.0.1:5173/admin` وسجّل بحساب Google المحدد في `ADMIN_EMAIL` لإضافة المنتجات وتعديلها وحذفها ومتابعة الطلبات. دليل إعداد Neon وGoogle وBlob موجود في [server/SETUP-FREE-DATABASE.md](server/SETUP-FREE-DATABASE.md).

عند تشغيل المشروع محليًا من دون `DATABASE_URL`، يستخدم الخادم ملفات JSON للتطوير. على Vercel يلزم إعداد `DATABASE_URL` وتسجيل دخول Google قبل استخدام لوحة الإدارة، وإعداد Blob قبل رفع ملفات جديدة.
